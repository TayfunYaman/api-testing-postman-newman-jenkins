# API Testing Portfolio – Postman, Newman & Jenkins CI

This project demonstrates automated API testing using **Postman**, executed via **Newman**, and fully integrated into a **Jenkins CI pipeline** with **JUnit reporting**.

The goal of this project is to showcase a real-world QA automation workflow where API tests are triggered and reported through a Continuous Integration process.

---

## 🧪 Project Overview

- Public API tested: **Swagger Petstore API**
- Test types:
  - Positive & negative API tests
  - CRUD operations
  - Status code & response validations
- Execution:
  - Tests are executed **only via Jenkins**
  - No local/manual execution required
- Reporting:
  - Jenkins-native **JUnit test reports**
  - Build fails automatically on test failures

## 🚀 Jenkins CI Workflow

1. Jenkins pulls the project from GitHub
2. Newman is installed on the Jenkins node
3. Postman API tests are executed via Newman
4. Test results are exported as **JUnit XML**
5. Jenkins publishes test results and marks the build as:
   - ✅ **SUCCESS** if all tests pass
   - ❌ **FAILURE** if any test fails

---

## ⚙ Jenkins Execution Command

The following command is executed inside Jenkins:

```bash
npx newman run postman/PetShopApi.postman_collection.json \
-e postman/PetShopApi.postman_environment.json \
--reporters cli,junit \
--reporter-junit-export newman/PetShopApi.xml
```
